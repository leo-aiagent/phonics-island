# 拼读探险岛

家庭自然拼读复习网页应用，静态托管于 GitHub Pages。

网址：https://leo-aiagent.github.io/phonics-island/

- Android：用 Chrome 打开网址，菜单中选择安装应用 / 添加到主屏幕。
- iPhone：用 Safari 打开网址，分享 → 添加到主屏幕。
- 使用前先选择孩子已经学过的规则，下载音频；显示“15 词基础包，已离线就绪”后可以断网练习。
- 当前提供 15 个整词音频，包括 sh/ch 的 10 个训练词。其他尚未准备的资源对应任务不开放。
- 学习记录、设置与录音保存在当前浏览器，各设备分别记录；不自动跨设备同步。
- 网页公开可访问。本仓库仅包含静态运行文件与许可，不包含家庭学习记录、录音、备份或本机测试日志。
- 默认家长码 2468，可在家长区修改，仅用于减少误触。

本仓库为已构建发布文件，维护源代码在使用者本机单独保存。
